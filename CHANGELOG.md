# Changelog

## 0.1.0

- First public preview: registered-workspace explorer, read-only code viewer, embedded preview, and persistent interactive PTY terminal.
- Preview now expands the official right details column and Terminal participates in the bottom conversation layout; only Files remains floating.
- Terminal input, output, paste, history keys, completion, `Ctrl+C`, and `Ctrl+L` share one focusable terminal surface instead of a command form.
